# Paper Float Translator

Desktop floating translator for academic reading. Select English text in another app, press the global shortcut, and get a DeepSeek-powered Chinese translation near the cursor.

## Development

```bash
npm install
npm run dev
```

## Useful Scripts

```bash
npm run test
npm run typecheck
npm run build
```

The first implementation targets the desktop core loop. See [docs/PROJECT_PLAN.md](docs/PROJECT_PLAN.md) for the fixed architecture and implementation path.
